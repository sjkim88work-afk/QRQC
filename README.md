# QRQC

공정품질 신속대응회의(QRQC) 대시보드와 신속대응 추적표(Fast Response Tracking Sheet)를 관리하는 Windows 데스크톱 프로그램입니다.

## 주요 기능

- **대시보드**: 공정불량 PPM 추이, 불량유형 Pareto, 라인별 PPM 추이·현황, 오늘 다룰 항목
- **회의 진행 순서 1~6**: 단계 버튼으로 해당 화면·필터 이동, 20분 경과 타이머
- **신속대응 추적표**: Exit Criteria 9개 항목(24HR·2D·7D·9D·10D·14D) R/Y/G 관리
  - 계획일은 발견일 기준 자동 계산, 계획일 초과 시 자동 R
  - 항목별 상세 입력 창: 완료일자·확인자·상세내용·첨부(사진, PDF, 엑셀 등 원본 저장)
  - 회의 모드, 화면 맞춤·배율, CSV(엑셀) 내보내기
- **회의 결정사항**: 담당·기한 관리, 미완료 이월, 회의록 복사
- **실적 입력**: 라인별 생산수량·불량유형별 수량 → 대시보드 그래프 자동 갱신
- **설정**: 데이터 폴더, 라인 목록, 불량유형, 목표 PPM

## 실행

1. Python 3.12 설치 ("Add python.exe to PATH" 체크)
2. `1_run.bat` 더블클릭 (첫 실행 시 pywebview 설치)
3. 데이터 폴더 지정 — 팀이 함께 쓰려면 공유폴더(예: `\\서버\품질\신속대응`)

배포용 실행 파일: `2_build_exe.bat` → `dist\QRQC_Tracker.exe`

자세한 내용은 [README_사용법.txt](README_사용법.txt)를 참고하세요.

## 구조

```
app.py            내장 서버(127.0.0.1 전용) + 프로그램 창(pywebview, 없으면 브라우저)
web/index.html    화면 (외부 CDN 없이 동작)
1_run.bat         실행
2_build_exe.bat   PyInstaller 단일 exe 빌드
```

데이터 폴더 구조:

```
settings.json          라인·불량유형·목표 PPM (공통)
issues/<id>.json       이슈 1건 = 파일 1개
decisions/<id>.json    회의 결정사항
production/<날짜>.json  일일 실적
files/<이슈>/<항목>/    첨부 원본
trash/                 삭제한 이슈·첨부 보관
exports/               내보내기 파일
```

- 파일은 임시 파일에 쓴 뒤 교체(원자적 저장)해 공유폴더에서 읽는 도중 깨지지 않습니다.
- 다른 사용자의 변경은 8초 간격으로 감지해 화면에 반영합니다.
- 같은 문서를 동시에 수정하면 나중에 저장한 내용이 남습니다.
