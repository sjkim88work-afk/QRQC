공정품질 신속대응회의 · 신속대응 추적표  v1.3.0
=====================================================

■ 설치 — Python 설치·관리자 권한 필요 없음 (QIS와 같은 방식)
 1. 아래 주소에서 QRQC-windows.zip 을 내려받습니다. (항상 최신 버전)
    https://github.com/sjkim88work-afk/QRQC/releases/latest/download/QRQC-windows.zip
 2. 받은 zip을 우클릭 → [압축 풀기]로 풉니다. zip 안에서 바로 실행하지 마세요.
 3. 풀린 QRQC 폴더를 원하는 곳에 둡니다. 예: C:\QRQC 또는 문서\QRQC
    - QRQC.exe 만 따로 옮기지 말고 폴더째 두세요. (_internal 폴더가 함께 있어야 합니다)
    - C:\Program Files 처럼 관리자 권한이 필요한 위치는 피하세요.
    - 바탕화면 바로 가기: QRQC.exe 우클릭 → [바로 가기 만들기]
 4. QRQC.exe 를 더블클릭합니다.
    - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누르세요.
    - 프로그램 창 대신 안내 창과 함께 브라우저로 열리면, 받은 zip을 우클릭 → 속성 →
      아래쪽 "차단 해제" 체크 → 확인 후 다시 압축을 풀어 보세요. 그래도 같으면 IT에
      QRQC 폴더 예외 등록을 요청하세요.
 5. 처음 열리면 "데이터 폴더 선택" 창이 뜹니다.
    - 혼자 시험해 볼 때: 제안된 내 문서\QRQC_데이터 그대로 [이 폴더 사용]
    - 팀이 함께 쓸 때: 공유폴더(예: \\서버\품질\신속대응)를 지정
      다른 PC에서도 QRQC를 실행하고 같은 공유폴더를 지정하면 같은 데이터를 봅니다.
 6. 사용법을 익히려면 [신속대응 추적표] 탭 → [예시 데이터 불러오기]
    다 둘러본 뒤 [예시 데이터 삭제]를 누르면 예시만 지워집니다.
 7. 새 버전이 나오면 같은 주소에서 받아 압축을 풀고, 기존 QRQC 폴더를 통째로 바꾸면 됩니다.
    데이터는 공유폴더의 qrqc.db에, PC별 설정은 %LOCALAPPDATA%\QRQC 에 있어 그대로 유지됩니다.

■ (참고) 소스에서 직접 실행·빌드 — Python 3.12 필요
 - 1_run.bat      : 소스로 바로 실행 (첫 실행 때 pywebview 설치)
 - 2_build_exe.bat: dist\QRQC 폴더(QRQC.exe) 직접 빌드

■ 팀이 함께 쓰는 방식
 - 모든 데이터가 공유폴더의 데이터베이스 파일 qrqc.db 하나에 저장됩니다.
 - 여러 PC가 동시에 저장해도 차례로 기다렸다가 저장되므로 파일이 깨지지 않습니다.
 - 다른 사람이 수정한 내용은 8초 안에 내 화면에 자동으로 반영됩니다.
 - 같은 이슈를 두 사람이 동시에 고치면 나중에 저장한 내용이 남습니다.
   회의 중에는 한 사람이 화면을 띄워 입력하는 것을 권합니다.
 - 화면 오른쪽 위 점이 초록색이면 데이터 폴더에 연결된 상태, 빨간색이면 연결이 끊긴 상태입니다.

■ 데이터 폴더 구조
 qrqc.db      이슈, Exit Criteria 상세, 첨부자료(원본), 회의 결정사항, 설정이 모두 들어 있는 데이터베이스
 backups\     프로그램을 켤 때 하루 한 번 자동 백업 (최근 30개 보관). 설정 탭의 [지금 백업]으로도 만들 수 있음
 exports\     [엑셀로 내보내기]로 만든 파일
 ※ 복구가 필요하면 프로그램을 모두 끈 뒤 backups의 파일을 qrqc.db 이름으로 바꿔 덮어쓰세요.
 ※ 엑셀·Power BI에서 SQLite ODBC 드라이버로 qrqc.db의 v_issues 뷰를 연결하면 이슈 현황을 바로 조회할 수 있습니다.
 ※ v1.0(JSON 파일 저장)으로 쓰던 데이터는 처음 실행할 때 자동으로 데이터베이스에 옮겨집니다.

■ 기능 요약
 - 대시보드: 진행 이슈·R·봉쇄 미완료·Exit Criteria 달성률, 라인별 이슈 현황, 오늘 다룰 항목
 - 회의 순서 1~6 버튼: 누르면 해당 화면·필터로 이동, 경과 시간 표시
 - 신속대응 추적표: Exit Criteria 24HR~14D, 계획일 초과 시 자동 R
   · R/Y/G 칸을 누르면 상태 전환, 칸의 빈 곳을 누르면 상세 입력 창
   · 상세 입력 창: 완료일자, 확인자, 상세내용, 첨부(끌어놓기·파일 선택·캡처 붙여넣기)
   · 첨부 가능 형식: PDF, 이미지(JPG·PNG·GIF·BMP·WEBP), 엑셀(XLSX·XLSM·XLS·CSV), 파일당 50MB
   · [열기]는 엑셀·PDF 뷰어 등 PC의 기본 프로그램으로 열고, [저장]은 원하는 위치에 파일로 저장
 - 회의 결정사항: 담당·기한 관리, 미완료 이월, 회의록 복사
 - 설정: 데이터베이스 위치·백업, 라인(발견장소) 목록, 순번 형식
   · 순번 형식 예: PHA-{YY}-{MM}-{NN} → PHA-26-11-01 (매월 1부터)
                   QRQC-{YYYY}-{NNN} → QRQC-2026-001 (매년 1부터)
                   FR-{NNNN} → FR-0001 (계속 증가)

■ 문제가 생겼을 때
 - 창이 안 뜨고 바로 꺼짐: %LOCALAPPDATA%\QRQC\logs\qrqc.log 에 원인이 남습니다.
 - 점검: 명령 프롬프트에서 QRQC.exe --selftest 점검.json 을 실행하면 서버·DB·첨부·창 구성요소를
   점검한 결과가 점검.json 에 저장됩니다.
 - "데이터 폴더에 접근할 수 없음": 공유폴더 네트워크 연결(드라이브 연결, VPN)을 확인하세요.
 - 프로그램 창 대신 브라우저로 쓰고 싶을 때: python app.py --browser
