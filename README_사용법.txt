공정품질 신속대응회의 · 신속대응 추적표  v1.0.0
=====================================================

■ 처음 실행 (Python으로 바로 실행)
 1. Python 3.12를 설치합니다.  https://www.python.org/downloads/
    설치 첫 화면에서 "Add python.exe to PATH"를 반드시 체크하세요.
    (3.13 이상에서는 프로그램 창 부품이 설치되지 않을 수 있습니다.
     그래도 브라우저로 열려서 기능은 똑같이 쓸 수 있습니다.)
 2. 이 폴더의 1_run.bat 을 더블클릭합니다.
    첫 실행 때만 프로그램 창 부품(pywebview)을 인터넷에서 설치하느라 1분 정도 걸립니다.
 3. 처음 열리면 "데이터 폴더 선택" 창이 뜹니다.
    - 혼자 시험해 볼 때: 제안된 내 문서\QRQC_데이터 그대로 [이 폴더 사용]
    - 팀이 함께 쓸 때: 공유폴더(예: \\서버\품질\신속대응)를 지정
 4. 사용법을 익히려면 [신속대응 추적표] 탭 → [예시 데이터 불러오기]
    다 둘러본 뒤 [예시 데이터 삭제]를 누르면 예시만 지워집니다.

■ 다른 PC에 나눠 줄 실행 파일(.exe) 만들기
 1. 2_build_exe.bat 을 더블클릭합니다. (1~3분)
 2. dist 폴더에 QRQC_Tracker.exe 파일 하나가 만들어집니다.
 3. 이 파일만 다른 PC에 복사하면 Python 없이 더블클릭으로 실행됩니다.
    각 PC에서 처음 실행할 때 모두 같은 공유폴더를 데이터 폴더로 지정하세요.
 ※ 회사 백신이 처음 보는 exe를 막을 수 있습니다. 그때는 IT에 예외 등록을 요청하세요.

■ 팀이 함께 쓰는 방식
 - 이슈 1건, 실적 1일, 결정사항 1건이 각각 JSON 파일 1개로 공유폴더에 저장됩니다.
 - 다른 사람이 수정한 내용은 8초 안에 내 화면에 자동으로 반영됩니다.
 - 같은 이슈를 두 사람이 동시에 고치면 나중에 저장한 내용이 남습니다.
   회의 중에는 한 사람이 화면을 띄워 입력하는 것을 권합니다.
 - 화면 오른쪽 위 점이 초록색이면 데이터 폴더에 연결된 상태, 빨간색이면 연결이 끊긴 상태입니다.

■ 데이터 폴더 구조
 settings.json         라인 목록, 불량유형, 목표 PPM (설정 탭에서 수정)
 issues\               신속대응 이슈
 decisions\            회의 결정사항
 production\           일일 생산·불량 실적
 files\<이슈>\<항목>\   첨부자료 원본 (사진, PDF, 엑셀 등)
 exports\              [엑셀로 내보내기]로 만든 파일
 trash\                삭제한 이슈·첨부 (바로 지우지 않고 옮겨 둠 → 필요하면 되살릴 수 있음)
 ※ 공유폴더는 정기 백업 대상에 포함해 두세요.

■ 기능 요약
 - 대시보드: PPM 추이, 불량유형 Pareto, 라인별 추이·현황, 오늘 다룰 항목
 - 회의 순서 1~6 버튼: 누르면 해당 화면·필터로 이동, 경과 시간 표시
 - 신속대응 추적표: Exit Criteria 24HR~14D, 계획일 초과 시 자동 R
   · R/Y/G 칸을 누르면 상태 전환, 칸의 빈 곳을 누르면 상세 입력 창
   · 상세 입력 창: 완료일자, 확인자, 상세내용, 첨부(끌어놓기·파일 선택·캡처 붙여넣기)
   · 첨부는 [열기]를 누르면 엑셀·PDF 뷰어 등 PC의 기본 프로그램으로 열림
 - 회의 결정사항: 담당·기한 관리, 미완료 이월, 회의록 복사
 - 실적 입력: 라인별 생산수량과 불량유형별 수량 입력 (Enter로 아래 칸 이동)
 - 설정: 데이터 폴더 변경, 라인·불량유형·목표 PPM

■ 문제가 생겼을 때
 - 창이 안 뜨고 바로 꺼짐: 1_run.bat 대신 명령 프롬프트에서 python app.py --browser 로 실행하면
   오류 문장이 보입니다.
 - "데이터 폴더에 접근할 수 없음": 공유폴더 네트워크 연결(드라이브 연결, VPN)을 확인하세요.
 - 프로그램 창 대신 브라우저로 쓰고 싶을 때: python app.py --browser
