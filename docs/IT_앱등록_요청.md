# QRQC 웹앱 — Microsoft Entra ID 앱 등록 요청

품질팀 공정품질 신속대응회의(QRQC) 추적표를 아이폰·PC 브라우저에서 쓰기 위해, 회사 Microsoft 365 계정으로 로그인하는 앱 등록을 요청드립니다.

## 1. 동작 방식 요약

| 항목 | 내용 |
|---|---|
| 앱 종류 | 단일 페이지 애플리케이션(SPA). 브라우저에서만 동작하고 별도 서버가 없습니다 |
| 로그인 | Microsoft 공식 라이브러리(MSAL.js), 인증 코드 + PKCE |
| 권한 방식 | **위임 권한만** 사용 — 로그인한 사용자 본인이 접근할 수 있는 파일에만 접근 |
| 데이터 저장 위치 | 회사 OneDrive / SharePoint 폴더 (품질팀이 정한 공유 폴더 하나) |
| 비밀 값 | **사용하지 않음** (client secret · 인증서 불필요) |
| 화면 파일 위치 | GitHub Pages `https://sjkim88work-afk.github.io/QRQC/` — 화면 코드만 있고 회사 데이터는 없습니다 |

- 회사 데이터(이슈, 첨부 사진·PDF·엑셀, 회의 결정사항)는 Microsoft 365 밖으로 나가지 않습니다.
- 접근 토큰은 사용자 브라우저에만 저장되고 다른 서버로 전송하지 않습니다.
- 회사의 조건부 액세스·MFA 정책이 그대로 적용됩니다.

## 2. 등록해 주실 내용

Entra 관리 센터 › **앱 등록 › 새 등록**

| 항목 | 값 |
|---|---|
| 이름 | `QRQC 신속대응 추적표` |
| 지원되는 계정 유형 | **이 조직 디렉터리의 계정만** (단일 테넌트) |
| 리디렉션 URI — 플랫폼 | **단일 페이지 애플리케이션(SPA)** |
| 리디렉션 URI — 주소 | `https://sjkim88work-afk.github.io/QRQC/` (끝의 `/` 포함) |

**API 권한** › 권한 추가 › Microsoft Graph › **위임된 권한**

| 권한 | 쓰는 곳 |
|---|---|
| `User.Read` | 로그인한 사용자 이름 표시 (작성자 · 수정자 기록) |
| `Files.ReadWrite.All` | 팀 공유 폴더의 이슈 파일·첨부 읽기·쓰기 |

- `Files.ReadWrite`(All 없음)는 본인 OneDrive 파일만 다룰 수 있어, 팀원이 함께 쓰는 공유 폴더를 열 수 없습니다. 그래서 `.All`이 필요합니다. 위임 권한이므로 사용자 본인에게 권한이 있는 파일에만 접근합니다.
- 회사에서 사용자 동의를 막아 두었다면 **[관리자 동의 허용]**을 부탁드립니다.
- 응용 프로그램 권한(앱 전용 권한)과 client secret은 필요하지 않습니다.

## 3. 회신 부탁드리는 값

등록 후 **개요** 화면의 두 값을 알려 주세요. 둘 다 비밀 값이 아닙니다.

- 애플리케이션(클라이언트) ID
- 디렉터리(테넌트) ID

## 4. (품질팀) 받은 뒤 할 일

1. GitHub 저장소에서 `web/config.js`를 열고 연필 아이콘(편집)을 누릅니다.
2. 받은 값을 넣고 **Commit changes**를 누릅니다.
   ```js
   window.QRQC_CONFIG = {
     clientId: '애플리케이션(클라이언트) ID',
     tenantId: '디렉터리(테넌트) ID',
   };
   ```
3. 몇 분 뒤 `https://sjkim88work-afk.github.io/QRQC/`에 접속해 로그인합니다.
